# Asteroseismic f_Delta_nu Diagnostics

Research code for testing radius-dependent asteroseismic correction factors
in red-giant models and synthetic power spectra. The public release contains
the Python source and this usage guide. Model grids, generated spectra,
pipeline outputs, external executables, figures, thesis material, and local
research notes are intentionally excluded.

The code compares pySYD, BAM, ASFGrid, Li reference calculations, and
Gaia/APOKASC-based radius benchmarks. The original `1M0_0D01.7ALPHA` sequence
is treated as the nonadiabatic sequence; the Li grid is a separate reference
calculation and is not labelled nonadiabatic.

## Source Files

| File | Purpose |
| --- | --- |
| `one_shot.py` | Main workflow for synthetic spectra, pySYD, BAM, ASFGrid, and Li data preparation. |
| `plots.py` | Plotting and comparison utilities for the available pipelines and benchmarks. |
| `pySYD_one_shot.py` | pySYD wrapper and echelle-diagram utilities. |
| `requirements.txt` | Python dependencies for the core workflows. |

## Installation

From the repository root:

```bash
python3 -m venv .venv_plotting
.venv_plotting/bin/python -m pip install --upgrade pip
.venv_plotting/bin/python -m pip install -r requirements.txt
```

The repository is currently a script-based research project, not an
installable Python package.

The core dependencies are `numpy`, `pandas`, `scipy`, `matplotlib`, `astropy`,
and `pyarrow`. ASFGrid additionally requires the external `ebfpy` dependency.
pySYD and BAM are external tools and are not vendored in this repository.

## Data and External Tools

The scripts expect local input products generated by the model and pipeline
workflows. Typical files include:

- `old_lit_nonad_1M0_0D01.7ALPHA.csv`
- `1M0_0D01.7ALPHA_SYDDNU_added_synced_cols.csv`
- `1M0_0D01.7ALPHA_asfgrid_added_synced_cols.csv`
- `1M_li_added_synced_cols_l0.csv`
- `1M_li_asfgrid_l0.csv`
- `apokasc3_gaia_benchmark.tsv`

Large model directories and local pipeline installations are expected outside
the public repository. The `.gitignore` protects generated tables, spectra,
figures, notes, thesis sources, and local environments from accidental
commits. Obtain the exact data snapshot separately before reproducing an
analysis.

ASFGrid is expected locally at:

```text
asfgrid_code/asfgrid_v0.0.6/
```

Create its optional environment with:

```bash
python3 -m venv .venv_asfgrid
.venv_asfgrid/bin/python -m pip install ebfpy
```

BAM requires an external executable such as `fitdnu.sh`. Pass its path to the
workflow or configure `BAMHOME` according to the BAM installation.

## Tutorial

All commands should be run from the repository root after the required local
data and external tools are available.

### Create the workflow

```python
from one_shot import full_create

runner = full_create()
```

### Run Li l=0 data through ASFGrid

```python
runner.run_li_asfgrid_l0()
runner.plot_li_asfgrid_fdnu()
```

For a small setup test:

```python
runner.run_li_asfgrid_l0(run_limit=25)
```

### Run Li data through BAM

```python
runner.create_BAM_data_li(
    num_chunks=16,
    bam_executable="/path/to/fitdnu.sh",
)
```

### Generate plots

```python
from plots import all_plots

plotter = all_plots()
plotter.plot_legacy_comparison_suite()
plotter.plot_pysyd_echelle_suite((224, 251, 91))
plotter.plot_pysyd_cutoff_profile(251)
```

For the Gaia benchmark, first place the filtered APOKASC-3 table at
`apokasc3_gaia_benchmark.tsv`, then run:

```python
plotter.plot_apokasc3_gaia_benchmark()
plotter.plot_comprehensive_fdnu_benchmark(radius_cut=30.0)
plotter.plot_gaia_required_fdnu_comparison(radius_cut=50.0)
```

The plotting methods write generated figures to `plots_directory/`, which is
ignored by the public release.

### Regenerate diagnostic suites

```python
plotter.pysyd_cutoff()
plotter.unified_fdnu_jump_diagnostics()
plotter.nonad_vs_reference_diagnostics()
```

The Li inertia workflow requires the local Li parquet data:

```python
plotter = all_plots(load_li_raw=True)
plotter.plot_inertia_li()
```

```bash
python3 -m py_compile one_shot.py plots.py pySYD_one_shot.py

```

outside the public commit.
